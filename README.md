# 📄 DocTransform Studio

An all-in-one, ultra-fast, and 100% client-side Web Application for PDF operations, Image conversion, and Optical Character Recognition (OCR). Powered by JavaScript, HTML5, and CSS3, DocTransform Studio runs entirely inside your browser—ensuring complete privacy and lightning-fast performance without uploading your files to any external server.

## ✨ Features Overview

### 1. 🖼️ PDF to Image (High Resolution)
- Convert all PDF pages into crisp PNG images instantly.
- Individual page preview with quick download options.
- Download all converted page images in a single **ZIP package**.

### 2. 📄 Image to PDF Converter
- Convert JPG, PNG, WEBP, and BMP images to high-quality PDF.
- **Smart Ascending / Descending Sorting:** Automatically parses numerical page names (e.g., `page-1`, `page-2`, `page-10`) into exact sequence.
- **HTML5 Drag & Drop Reordering:** Re-arrange pages easily before compiling into PDF.

### 3. 🧩 PDF Merger & Page Organiser
- Combine multiple PDF documents into a single file.
- Delete unnecessary pages or rotate individual pages (90° left/right).

### 4. 🖊️ Canvas Pen & Signature Tool
- Draw, annotate, write notes, or add your digital signature directly onto PDF pages before output.

### 5. 🔍 Image to Text (OCR)
- Extract editable text from images seamlessly.
- Multi-language support: **Bengali** (`ben`) and **English** (`eng`).
- Copy extracted text to clipboard or export as `.txt` document with one click.

## 🔒 100% Privacy & Security

- **Zero Server Processing:** All tasks (PDF processing, image rendering, OCR) are performed locally inside your device browser via `pdf.js`, `pdf-lib`, `jspdf`, and `tesseract.js`.
- Your sensitive documents and photos never leave your device!

## 🛠️ Built With

- **HTML5 & Modern CSS3** (Glassmorphism & Responsive UI)
- **PDF.js** (PDF rendering engine)
- **PDF-Lib** (PDF manipulation & merging)
- **jsPDF** (PDF generation)
- **Tesseract.js** (Browser-based OCR)
- **SortableJS** (Drag and drop list builder)

## 📦 How to Deploy Manually

### Option A: GitHub Pages
1. Fork or Clone this repository.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/root`.
4. Click **Save** and your site will be live in 1-2 minutes!

### Option B: Vercel / Netlify
1. Connect your GitHub repository to Vercel or Netlify.
2. Set Build Settings as static / zero-config.
3. Deploy instantly!
